# Tech AI Ops — Static Website

This repository contains a modern, production-ready static website for **Tech AI Ops**. It's designed for deployment using GitHub Pages (or any static host).

Features
- Light theme with cyan→blue→purple animated gradient
- Glassmorphism cards and modern SaaS/AI styling
- Mobile responsive and accessible
- Smooth scroll, scroll-reveal animations, hover effects
- Lightweight SVG assets (no external libraries required)
- SEO optimized with meta tags and JSON-LD

Files
- `index.html` — main site
- `style.css` — all styles
- `script.js` — small interactive behaviors
- `assets/logo.svg` — vector brand logo
- `assets/hero-illustration.svg` — illustration used in hero & portfolio
- `README.md` — this file

How to use
1. Create a new GitHub repository (or use an existing one).
2. Add the files and folders exactly as shown here.
3. In the repository settings, enable **GitHub Pages** from the `main` branch (or the branch you use).
4. Optionally, configure a custom domain (`http://www.techaiops.online/`) via repository settings and DNS.

Customization
- Replace the SVGs in `assets/` with your brand assets.
- Update the contact details and links in `index.html`.
- Connect the contact form to your preferred email service (Formspree, Netlify Forms, or a server endpoint).

Performance & SEO tips
- Keep images SVG or optimized WebP/Compressed JPEG.
- Use a CDN for any large assets if needed.
- Add hreflang or multi-language markup if you plan to support other locales.
